# Changelog

## 0.1.0

- Player vidéo en boucle dans un panneau à côté de l'éditeur
- Source : fichier local, dossier (lecture aléatoire enchaînée), URL directe ou YouTube
- Lecture muette par défaut, vitesse réglable, pause automatique quand l'onglet est masqué
- Bouton dans la barre d'état et raccourci `Ctrl+Alt+S` / `Cmd+Alt+S`
